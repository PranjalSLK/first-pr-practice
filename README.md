# first-pr-practice

A small practice repository for learning the GitHub pull request workflow.

## What's here

- `README.md` — this file.
- `notes.md` — a scratch file for practice edits.

## Making a practice pull request

1. Create a branch: `git switch -c my-change`
2. Edit a file (for example, `notes.md`) and commit it.
3. Push the branch: `git push -u origin my-change`
4. Open a PR: `gh pr create --fill`
